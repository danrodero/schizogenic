# Product vision

## Vision

Schizogenic helps one person understand and intentionally organize their life
through a coherent set of tracking modules.

The first module is fast, trustworthy time tracking inspired by Toggl's timer
workflow. Later modules may cover finances, habits, goals, and other personal
signals. A shared platform should let those modules coexist without forcing
them into one undifferentiated data model.

## Product principles

1. **Capture must be quick.** Recording an activity should interrupt the
   activity as little as possible.
2. **History must be trustworthy.** Time records and later personal records
   need explicit, auditable semantics.
3. **Interfaces are peers.** Web and CLI clients should expose the same domain
   capabilities through stable contracts.
4. **Mobile use is normal.** The web experience must work well at phone
   viewport sizes, not merely shrink to fit.
5. **Modules remain bounded.** New tracking domains should share platform
   capabilities without coupling their business rules.
6. **The product earns complexity.** Begin with one user and one deployable
   system unless confirmed requirements justify more.

## Learning vision

The repository is successful only if the developer can explain, implement,
test, operate, and defend its design. Passing review matters more than shipping
quickly, and production standards apply from the first feature.
